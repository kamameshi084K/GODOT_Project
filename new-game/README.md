# ブロックス

Godot 4.5.1で動く、2〜4人の3Dブロックスです。友人同士でホストのIPアドレスを指定して対戦します。UIは日本語です。

## 起動

Windowsで `C:\GodotEngine\Godot_v4.5.1-stable_win64.exe` を起動し、このフォルダの `project.godot` を読み込んで「プロジェクトを実行」を押します。実行ファイルが別の場所にある場合はGodot 4.5.1の実行ファイルを使ってください。

コマンドラインからは次のように起動できます。

```powershell
& 'C:\GodotEngine\Godot_v4.5.1-stable_win64.exe' --path 'C:\Users\ka07z\Documents\GitHub\GODOT_Project\new-game'
```

## 遊び方

- タイトルでニックネームを入力し、「部屋を作る」か「部屋に参加する」を選びます。参加者はホストのIPアドレスまたはホスト名とUDPポートを入力します。既定のポートは **24567/UDP** で、ホストと参加者は同じ番号を使います。
- ロビーには席、担当予定の色、準備状態が表示されます。2〜4人全員が「準備完了」にしてから、ホストが「対戦開始」を押します。全員の画面準備が終わると青から始まります。
- 左の一覧から駒を選び、盤面上で配置プレビューを見て左クリックで確定します。不合法な場所には理由を表示します。使用済みの駒は選べません。
- `Q` / `E` で回転、`F` で反転します。右クリックまたは `Esc` で選択解除します。中ボタンを押しながらドラッグすると視点が回り、ホイールでズームします。「視点を戻す」で初期位置に戻せます。
- 「このPCで順番に遊ぶ」では、通信を使わずに1台で席を交代して遊べます。

## ルール

盤面は20×20マス。青・黄・赤・緑の各色には21種類、合計89マスの駒があります。各色の初手は開始角を覆い、以後は同じ色と角で接しなければなりません。同じ色の辺同士は接触できません。違う色とは辺でも角でも接触できます。手番は青→黄→赤→緑です。合法手がない色は自動パスし、4色すべて配置不能で終了します。

| 人数 | 担当 |
| --- | --- |
| 2人 | 席1が青・赤、席2が黄・緑 |
| 3人 | 席1が青、席2が黄、席3が赤。共有の緑は緑の手番ごとに席1→2→3と交代 |
| 4人 | 席1から順に青・黄・赤・緑 |

色の得点は未配置の1マスにつき−1点です。21個をすべて置けば＋15点、最後の1個が1マス駒ならさらに＋5点です。2人戦では担当2色を合算し、3人戦では緑の得点を個人の勝敗に含めません。同点は同順位です。終了画面には色ごとの残りマス数、ボーナス、合計と個人の順位を表示します。

## ネットワーク接続

同じPC内では参加先を `127.0.0.1` にします。LANではホストPCのプライベートIPアドレスを使います。ホストで `ipconfig` を実行すると確認できます。ホストのWindowsファイアウォールでゲームの受信UDP通信を許可してください。

インターネット越しでは、ホスト側ルーターからホストPCへ使用ポートの **UDP** 転送が必要です。参加者はホスト側のグローバルIPアドレスまたは到達可能なホスト名を指定します。ルーターの多段NATやCGNATなどでポート転送が使えない環境では、そのままでは接続できません。到達可能なVPN等を用意するか、ネットワーク側の設定を確認してください。ルームコードだけで接続する仕組みはありません。[Godot 4.5の公式ネットワーク説明](https://docs.godotengine.org/en/4.5/tutorials/networking/high_level_multiplayer.html)も参照してください。

対戦途中の参加や復帰、ホスト交代には対応していません。誰かが切断するとその対戦を中止します。通常終了後はホストがロビーに戻し、再び全員が準備すると再戦できます。

## Windows向け実行ファイルの作成

Godot 4.5.1のエディターでプロジェクトを開き、「プロジェクト」→「エクスポート」で「Windows Desktop」を追加し、x86_64向けの出力先を選んでエクスポートします。対応する4.5.1のエクスポートテンプレートが必要です。テンプレートが未導入の場合はエクスポート画面の案内に従って導入してください。作成したexeと必要なデータファイルを友人へ渡します。[Godot 4.5のWindowsエクスポート説明](https://docs.godotengine.org/en/4.5/tutorials/export/exporting_for_windows.html)を参照してください。

この環境ではエクスポートテンプレートと実機でのGUI操作を確認していないため、Windowsビルドの生成は未検証です。
